# Mouse Image Distortion

A list of text rows. Hovering a row reveals a floating image that follows the
cursor; the image warps (vertex displacement driven by mouse velocity) using a
custom GLSL shader, creating a liquid-like distortion. Built on
`@react-three/fiber`, `@react-three/drei` and `three` — no Framer Motion
distortion required.

## Usage

```tsx
import { MouseImageDistortion } from "@/components/ui/mouse-image-distortion"

const items = [
  { title: "Aurora", subtitle: "Light in the dark", imageUrl: "/aurora.jpg" },
  { title: "Basalt", subtitle: "Stone and silence", imageUrl: "/basalt.jpg" },
]

export function Projects() {
  return <MouseImageDistortion items={items} />
}
```

## How it works

The component renders two layers:

1. The text list (rows), styled with `mix-blend-difference` so the white text
   inverts the background.
2. A fixed full-screen `<Canvas>` (pointer-events none) containing a 3D plane
   mesh textured with the hovered row's image.

On hover, the mesh fades in (opacity 0 → 1 over 0.2s) and its texture swaps to
the hovered row's image. The mesh follows the cursor: its position is mapped
from screen pixels to world space, smoothed by a `0.1` lerp per frame. The
vertex shader displaces vertices with `sin(uv.y * PI) * uDelta.x * uAmplitude`
(and the symmetric form on Y), where `uDelta` is the per-frame mouse delta —
this is what produces the liquid warp. The fragment shader samples the texture
and multiplies by `uAlpha`.

## Dependencies

- `three`
- `@react-three/fiber`
- `@react-three/drei`

## Performance

- A single canvas and a single mesh; only the texture and opacity change on
  hover.
- Vertex displacement runs on the GPU; no React re-renders during movement.

## Accessibility

- Rows are not focusable by default; consider wrapping titles in links for
  keyboard navigation.
- The canvas is `pointer-events-none` and decorative.
