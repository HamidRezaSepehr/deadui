# Mouse Image Distortion

A 3D component using Three.js + GLSL. Hover any row in the list — that row's image
appears on a full-bleed plane that follows the cursor. Move the mouse quickly and
the image bends via a GLSL vertex shader; move slowly and it stays flat.

## How the velocity warp works

The vertex shader receives a `uDelta` uniform that is the gap between the raw cursor
position and the lagged (smoothed) cursor position. Faster movement produces a larger
delta, which displaces the plane vertices more — so the image warps more when you
move quickly and flattens when you slow down.

```glsl
newPosition.x += sin(uv.y * PI) * uDelta.x * uAmplitude;
newPosition.y += sin(uv.x * PI) * uDelta.y * uAmplitude;
```

## Blend note

`mix-blend-difference` requires a solid `bgClassName` (default `bg-black`) to look
correct. Pairing with smooth-scroll (Lenis) is optional and not bundled.

## Dependencies

- `three`

- `@react-three/drei`

## Performance

- One `<Canvas>` per component instance, one plane, one shader.
- Mouse position is stored in a `useRef`, **not** `useState` — no React re-render on
  `mousemove`.
- `useFrame` updates the shader uniforms and mesh position directly.
- Textures loaded once per item via `useTexture`.

## Accessibility

- Semantic list items with real text content.
- The 3D canvas layer is `pointer-events-none` — it never intercepts focus or clicks.
- The component is purely visual; no critical information is conveyed through the warp.
