# Mouse Image Distortion

A list of text rows. Hover over any row: an image plane fades in behind the
cursor and warps with a liquid vertex displacement shader based on the speed
and direction of your mouse movement. The effect uses `@react-three/fiber` and
a custom GLSL vertex shader.

## How it works

A `<Canvas>` from `@react-three/fiber` is rendered as a `fixed` layer behind
the text list. Inside it, a subdivided `planeGeometry` (`15×15` segments) is
animated by a custom vertex shader:

```glsl
newPosition.x += sin(uv.y * PI) * uDelta.x * uAmplitude;
newPosition.y += sin(uv.x * PI) * uDelta.y * uAmplitude;
```

`uDelta` is the difference between the raw cursor position and a smoothed
(lerped) copy. When you move the mouse quickly, `uDelta` grows, the sine-based
displacement increases, and the image ripples like a liquid surface. The texture
fades in/out with a 200 ms Framer Motion animation.

The mouse is tracked via a `mousemove` listener on `window`. Smooth coordinates
are stored in Framer Motion's `useMotionValue` and interpolated in
`useFrame`. The mesh position is mapped from pixel space to Three.js viewport
space via `useTransform`.

## Dependencies

- `three` (WebGL renderer)
- `@react-three/fiber` (React renderer for Three.js)
- `@react-three/drei` (Three.js helpers)
- `framer-motion-3d` (Framer Motion for Three.js)
- `motion` (Framer Motion)

All are already present in the project.

## Performance

- The shader runs on the GPU; the JavaScript load is limited to `useFrame`
  (two lerps per frame) and the 200 ms fade animation on hover change.
- The subdivided plane (`15×15` segments) is a single draw call — 256 vertices.
- Images are preloaded by `useTexture`.

## Accessibility

- The text list is a semantic `<ul>` / `<li>`.
- The canvas is purely decorative and carries no focusable content.
- Reduced motion is not special-cased; the vertex displacement runs on GPU
  and cannot be disabled through CSS media queries.
