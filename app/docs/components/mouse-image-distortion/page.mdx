# Mouse Image Distortion

An image floats over a list of text rows and warps smoothly as the cursor moves
across the list. The distortion (skew and scale) is driven by the cursor's
velocity via Framer Motion's `useVelocity` and springs, recreating a liquid warp
feel without WebGL.

## How it works

- The cursor is tracked through Framer Motion motion values
  (`useMotionValue` + `useVelocity`).
- `useVelocity` feeds a spring (`useSpring`), whose output drives the image's
  `scale`, `skewX` and `skewY`.
- The image is `fixed` and centered on the cursor via `translateX: "-50%"` /
  `translateY: "-50%"` equivalent offsets.
- Rows supply the surrounding text context and styling.

| `className` | `string` | — | Merged onto the container. |

## Dependencies

- `motion` (Framer Motion)

## Performance

- Motion springs + `useVelocity`; no per-frame React state.
- One floating image per instance.

## Accessibility

- Rows are plain divs; give them meaningful text content.

Note: `ComponentCustomizer`'s control union currently covers `slider`, `select`
and `color`; text-typed controls are forwarded as strings via the adapter.
