# Mouse Image Distortion

A list of text rows where hovering reveals an image that follows the cursor and
warps with the cursor's movement velocity, using a custom Three.js GLSL vertex
shader.

## Usage

```tsx
import { MouseImageDistortion } from "@/components/ui/mouse-image-distortion";

const ITEMS = [
  {
    id: "1",
    title: "Richard Gaston",
    subtitle: "Photographer",
    imageUrl: "https://images.unsplash.com/photo-1506905925346-21bda4d32df4?w=1200&q=80",
  },
  // …more rows
];

export function Gallery() {
  return <MouseImageDistortion items={ITEMS} />;
}
```

## How it works

The component layers an HTML list over a full-screen React Three Fiber `<Canvas`:

1. The HTML layer renders the rows and tracks which one the pointer is on
   (`activeMenu`).
2. The 3D layer holds a single plane with a `THREE.ShaderMaterial` whose vertex
   shader reads the `uDelta` uniform.
3. Each `mousemove` updates the raw mouse position; the next frame compares it
   against a smoothed value and lerps towards it (factor `0.1`).
4. The delta (`raw − smoothed`) is written into `uDelta`, and the vertex shader
   displaces the plane:

```glsl
newPosition.x += sin(uv.y * PI) * uDelta.x * uAmplitude;
newPosition.y += sin(uv.x * PI) * uDelta.y * uAmplitude;
```

5. The displaced position is projected through the normal MVP matrix, so the
   image ripples like a liquid surface as the cursor moves.

The opacity of the image cross-fades over `0.2s` when the hovered row changes.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `DistortionItem[]` | — | Rows to render. Each row: `id`, `title`, optional `subtitle`, `imageUrl`. |
| `amplitude` | `number` | `0.0005` | Distortion strength, the `uAmplitude` uniform. |
| `imageScale` | `number` | `0.225` | Image scale relative to the viewport. |
| `textSize` | `string` | `"text-[4vw]"` | Tailwind text-size class for row titles. |
| `textColor` | `string` | `"text-white"` | Tailwind text-color class for row titles. |
| `rowPadding` | `string` | `"p-5"` | Tailwind padding class for each row. |
| `rowBorderColor` | `string` | `"border-white/20"` | Tailwind border-color class for row dividers. |
| `rowHoverBgColor` | `string` | `"bg-white/5"` | Tailwind background class for the hovered row. |
| `className` | `string` | — | Merged onto the root container. |

## Dependencies

- `three`
- `@react-three/fiber`
- `@react-three/drei`
- `framer-motion`
- `framer-motion-3d`

## Performance

- One `<Canvas>` per component instance, one plane, one shader.
- The mouse delta is computed in `useFrame`; no React state is touched per frame.
- Textures are loaded once per item via `useTexture`.

## Accessibility

- The rows are semantic list items with real text content.
- The list layer uses `mix-blend-difference` and is not interactive itself;
  hover state lives on the `<li>` elements.
