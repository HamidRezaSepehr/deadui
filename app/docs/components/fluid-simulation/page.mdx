# Fluid Simulation

A real-time WebGL fluid dynamics simulation with mouse interaction, velocity advection,
and density rendering. Features splatting, blurring, and display shaders for live fluid
visualisation. Tier: Pro.

## Installation

```bash
npx deadui@latest add fluid-simulation
```

## Usage

```tsx
import { FluidSimulation } from "@/components/ui/fluid-simulation"

<FluidSimulation variant="default" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "particle" \| "border"` | `"default"` | Visualisation mode |

### Variants

- **default**: Base fluid simulation with mouse interaction and velocity advection
- **particle**: Renders particles advected by the fluid flow with trailing effect
- **border**: Displays only the fluid boundary/edge detection

## Dependencies

- `three`
- `@react-three/fiber`
- `@react-three/drei`

## Performance

- Bundle size: ~45KB (Three.js + @react-three/fiber + @react-three/dři)
- 60fps on mid-range hardware with GPU-accelerated GLSL shaders
- Respects `prefers-reduced-motion`

## Accessibility

- Respects `prefers-reduced-motion`: reduces shader complexity and disables mouse forces
