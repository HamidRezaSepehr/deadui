# Fluid Simulation

An interactive WebGL fluid dynamics effect where users can stir colourful ink trails with their cursor. Click to burst, move to swirl — a seamless, GPU-driven particle-free simulation.

## Installation

<InstallTabs componentName="fluid-simulation" />

## Usage

```tsx
import { FluidSimulation } from "@/components/ui/fluid-simulation"

<FluidSimulation className="h-screen w-full" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `config` | `FluidConfig` | `{}` | Partial configuration object. Omitted keys use defaults. |
| `className` | `string` | `""` | Tailwind classes forwarded to the canvas element. |

### FluidConfig

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `SIM_RESOLUTION` | `number` | `128` | Simulation grid resolution (lower = faster). |
| `DYE_RESOLUTION` | `number` | `1024` | Output dye resolution (higher = sharper). |
| `DENSITY_DISSIPATION` | `number` | `1` | How quickly the ink fades. Higher = faster fade. |
| `VELOCITY_DISSIPATION` | `number` | `0.2` | How quickly the fluid slows down. |
| `PRESSURE` | `number` | `0.8` | Pressure value used in the pressure solver. |
| `PRESSURE_ITERATIONS` | `number` | `20` | Solver iterations. Higher = more accurate, slower. |
| `CURL` | `number` | `30` | Vorticity / swirl strength. Higher = more swirls. |
| `SPLAT_RADIUS` | `number` | `0.25` | Radius of each pointer splat (normalised). |
| `SPLAT_FORCE` | `number` | `6000` | Force applied per pointer movement. |
| `SHADING` | `boolean` | `true` | Enable/disable lighting shading. |
| `COLOR_UPDATE_SPEED` | `number` | `10` | How often the colour palette rotates. |
| `BACK_COLOR` | `{ r, g, b }` | `{0,0,0}` | Background colour (not used when transparent). |

## Dependencies

- None (pure WebGL, zero external packages)

## Performance

This is a heavy WebGL component that runs a full fluid simulation at 60fps. Use it as a background element (fixed position, full viewport). On low-end devices, reduce `SIM_RESOLUTION` (e.g., 64) and `DYE_RESOLUTION` (e.g., 512).

## Accessibility

- The component renders a `<canvas>` element. Provide an `aria-label` via props for screen readers.
- Respects `prefers-reduced-motion`: the canvas is still rendered, but no animation occurs.
