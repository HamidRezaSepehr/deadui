# Fluid Simulation

An interactive WebGL fluid dynamics effect where users can stir colorful ink trails with their cursor.

This component is heavy and should ideally be used as a background element.

## Installation

```bash
npx deadui add fluid-simulation
```

## Usage

```tsx
import { FluidSimulation } from "@/components/ui/fluid-simulation"

export default function Page() {
  return (
    <FluidSimulation
      className="h-full w-full"
      config={{ CURL: 30, SPLAT_FORCE: 6000 }}
    />
  )
}
```

## Config

- `SIM_RESOLUTION`: Simulation grid resolution (default: 128)
- `DYE_RESOLUTION`: Dye texture resolution (default: 1024)
- `CAPTURE_RESOLUTION`: Capture resolution (default: 512)
- `DENSITY_DISSIPATION`: How quickly dye fades (default: 1)
- `VELOCITY_DISSIPATION`: Velocity decay rate (default: 0.2)
- `PRESSURE`: Pressure strength (default: 0.8)
- `PRESSURE_ITERATIONS`: Pressure solver iterations (default: 20)
- `CURL`: Vorticity/swirl strength (default: 30)
- `SPLAT_RADIUS`: Splat radius as fraction (default: 0.25)
- `SPLAT_FORCE`: Force applied on splat (default: 6000)
- `SHADING`: Enable shading (default: true)
- `COLOR_UPDATE_SPEED`: Color cycle speed (default: 10)
- `BACK_COLOR`: Background RGB color (default: `{ r: 0, g: 0, b: 0 }`)
