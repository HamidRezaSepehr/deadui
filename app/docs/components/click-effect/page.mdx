# Click Effect

A behavior-only component that renders one invisible overlay and replays a
mo.js burst at the pointer on every click. Effects are positioned in the
overlay's coordinate space, so a burst always lands exactly where you clicked —
scrolled or not. Point it at the whole page, or scope it to a single card.

## Usage

Page-wide — place it once near the root of your app (e.g. in `layout.tsx`) and
every click fires the effect at the pointer:

```tsx
import { ClickEffect } from "@/components/ui/click-effect"

export function RootClickEffect() {
  return <ClickEffect variant="virethos" />
}
```

Scoped — drop one inside any `relative` container (a card, a hero, a canvas)
and it becomes that container's own click effect:

```tsx
import { ClickEffect } from "@/components/ui/click-effect"

export function ClickableCard() {
  return (
    <div className="relative overflow-hidden rounded-xl border p-6">
      <ClickEffect variant="elarisca" scope="parent" />
      <h2>Click anywhere in this card</h2>
    </div>
  )
}
```

With `scope="parent"` the listener is attached to the component's parent
element rather than `window`, so clicks outside the container never fire, and
the burst is clipped to the container.

## Effects

All 15 presets are available: `virethos`, `zynthor`, `elarisca`, `gravonix`,
`xypheris`, `vorlana`, `klyntar`, `zerionis`, `marnixus`, `taviros`, `lothira`,
`xandura`, `dravonix`, `voltrisca`, `elvantis`. Set `variant="none"` to disable
the listener entirely without unmounting the component.

## Props

| Prop      | Type                 | Default      | Description                                                                                        |
| --------- | -------------------- | ------------ | -------------------------------------------------------------------------------------------------- |
| `variant` | `ClickEffectVariant` | `"virethos"` | The effect to replay on each click. `"none"` disables the listener.                                |
| `scope`   | `"page" \| "parent"` | `"page"`     | `"page"` listens on `window` (fixed overlay, viewport coordinates). `"parent"` listens on the parent element and renders inside it. |

## Behavior

- Renders a single invisible overlay (`aria-hidden`, `pointer-events: none`) —
  no visible DOM, no layout impact.
- `scope="page"` (default) attaches one `click` listener to `window` and
  renders into a fixed, viewport-sized overlay. `scope="parent"` attaches the
  listener to the component's parent element and renders into an
  absolutely-positioned overlay inside it, so the parent should be
  `position: relative`.
- Pointer coordinates are converted to overlay-relative values
  (`clientX - rect.left`, `clientY - rect.top`). mo.js positions shapes against
  their container, so this is what keeps the burst exactly on the click instead
  of drifting by the page's scroll offset.
- Every mounted instance builds its own mo.js animations via
  `createEffect(variant, overlay)`, so several instances — including two of the
  same variant — animate independently.
- Effects flagged `requiresGenerate` call `.tune(...).generate().replay()` to
  re-sample `rand(...)` values; effects flagged `useRandomCoords` add a random
  ±30px offset.
- Uses dynamic `import()` to load `@mojs/core` and the effect table **only in
  the browser**. It never runs during SSR, avoiding the `self`/`document`
  environment requirements of mo.js.
- Unmounting removes the listener and clears the overlay's mo.js nodes;
  switching `variant` rebuilds the effect in place.

## Notes

- **Performance:** Animations are built once per mount, not per click. On click,
  the code only calls `.tune(...).replay()` (plus `.generate()` when required) —
  no allocations per click.
- **Dependencies:** Requires `@mojs/core@1.3.0` (installed automatically by
  `deadui add click-effect`).
- **Browser-only:** `@mojs/core` touches `self`, `document` and `navigator` at
  module evaluation time. This component defers that import until after
  hydration and never executes on the server.
- **General clicks:** with `scope="page"`, remember that the listener is on
  `window` — every click in your app fires the effect. Use `scope="parent"` if
  you want it limited to one surface, and call `event.stopPropagation()` on any
  control that should not trigger a burst.
