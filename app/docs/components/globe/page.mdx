# Globe

A beautiful, high-performance, interactive 3D globe rendered entirely on the
GPU via WebGL using the lightweight `cobe` library. Fully configurable —
customise colours, markers, rotation speed, and lighting to match any brand.

## Usage

```tsx
import { Globe } from "@/components/ui/globe"

export function WorldMap() {
  return (
    <div className="w-full max-w-sm">
      <Globe size={400} />
    </div>
  )
}
```

### Custom colours and rotation speed

```tsx
<Globe
  size={400}
  dark={1}
  baseColor={[1, 0.4, 0.8]}
  markerColor={[0.1, 1, 0.6]}
  glowColor={[0.8, 0.2, 1]}
  autoRotateSpeed={0.015}
/>
```

### Adding location markers

Markers are specified as an array of objects with `location` (a `[latitude,
longitude]` tuple) and `size` (a brightness multiplier):

```tsx
const MY_LOCATIONS = [
  { location: [40.7128, -74.006], size: 0.08 }, // New York
  { location: [51.5074, -0.1278], size: 0.08 }, // London
  { location: [35.6762, 139.6503], size: 0.08 }, // Tokyo
]

;<Globe size={400} markers={MY_LOCATIONS} />
```

### Disabling auto-rotation

```tsx
<Globe size={400} autoRotate={false} phi={0.5} theta={0.3} />
```

`phi` and `theta` set the globe's initial orientation in radians.

## Props

| Prop              | Type                                  | Default             | Description                                                         |
| ----------------- | ------------------------------------- | ------------------- | ------------------------------------------------------------------- |
| `size`            | `number`                              | `400`               | Canvas width/height in pixels.                                       |
| `phi`             | `number`                              | `0`                 | Initial horizontal rotation (radians).                               |
| `theta`           | `number`                              | `0`                 | Initial vertical rotation (radians).                                 |
| `dark`            | `number`                              | `0`                 | Darkness level `0`–`1`. `1` = fully dark mode.                     |
| `diffuse`         | `number`                              | `1.2`               | Diffuse lighting intensity.                                          |
| `mapSamples`      | `number`                              | `16000`             | Number of samples for the procedural texture. Higher = smoother.    |
| `mapBrightness`   | `number`                              | `6`                 | Map brightness multiplier.                                           |
| `baseColor`       | `[number, number, number]`             | `[0.3, 0.3, 0.3]`  | Globe base colour as RGB `[0–1]` tuple.                            |
| `markerColor`     | `[number, number, number]`            | `[0.1, 0.8, 1]`    | Location marker colour as RGB `[0–1]` tuple.                        |
| `glowColor`       | `[number, number, number]`            | `[1, 1, 1]`        | Glow colour as RGB `[0–1]` tuple.                                   |
| `markers`         | `Marker[]`                            | `[]`                | Array of location markers.                                           |
| `opacity`         | `number`                              | `1`                 | Globe opacity `0`–`1`.                                              |
| `autoRotate`      | `boolean`                             | `true`              | Enable continuous auto-rotation.                                     |
| `autoRotateSpeed` | `number`                              | `0.01`              | Radians added to `phi` per render frame — higher = faster.          |
| `draggable`       | `boolean`                             | `false`             | Enable pointer drag to rotate the globe.                             |
| `className`       | `string`                              | —                   | Additional classes for the canvas element.                           |
| `...props`        | `HTMLAttributes<HTMLCanvasElement>`    | —                   | Spread onto the underlying `<canvas>`.                               |

### `Marker`

| Prop       | Type                  | Description                              |
| ---------- | --------------------- | ---------------------------------------- |
| `location` | `[number, number]`    | `[latitude, longitude]` in degrees.      |
| `size`     | `number`              | Brightness multiplier for this marker.  |
| `color`    | `[number, number, number]` | Custom RGB colour for this marker. |
| `id`       | `string`              | ID for CSS anchor positioning.          |

## Dependencies

The component requires the `cobe` WebGL library:

```bash
npm install cobe
```

Or let Dead UI handle it automatically:

```bash
npx deadui@latest add globe
```

## Performance

- Fully GPU-rendered via WebGL — no DOM manipulation during animation.
- Rotation updates use React refs, not state, so no re-render cycles.
- The canvas is sized at `size × devicePixelRatio` for sharp Retina output.
- `globe.destroy()` is called on unmount to release the WebGL context and prevent memory leaks.

## Accessibility

- The canvas is a decorative element; provide a text alternative or aria-label
  if the globe conveys meaningful geographic information.
- Under `prefers-reduced-motion` the globe still renders but rotation pauses
  (`autoRotate` can be set to `false`).
