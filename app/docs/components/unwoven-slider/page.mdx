# Unwoven Slider

An infinite image slider where photos unravel into loose threads at the edges, powered by Three.js and custom GLSL shaders. Drag to interact and release for momentum-based flinging.

## Features

- **Infinite Loop**: Images wrap continuously for seamless scrolling
- **Thread Unraveling**: Images split into horizontal threads that splay apart at the viewport edges
- **Interactive Dragging**: Click and drag to control movement with momentum
- **Customizable**: Fine-tune thread count, tear zones, card sizes, and more
- **WebGL Powered**: Smooth 60fps performance with custom shaders

## Usage

```tsx
import { UnwovenSlider } from "@/components/ui/unwoven-slider"

const images = [
  "https://images.unsplash.com/photo-1544005313-94ddf0286df2?w=800&q=80",
  "https://images.unsplash.com/photo-1554151228-14d9def656e4?w=800&q=80",
]

export default function Example() {
  return <UnwovenSlider images={images} />
}
```

## Configuration

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `threads` | `number` | `26` | Number of horizontal ribbons/threads per card |
| `segments` | `number` | `20` | Horizontal subdivisions per ribbon for smoother deformation |
| `cardMaxHeight` | `number` | `452` | Maximum pixel height of each card |
| `cardAspect` | `number` | `0.75` | Width/height ratio of cards |
| `cardGapRatio` | `number` | `0.11` | Gap between cards as fraction of card width |
| `cardRadius` | `number` | `20` | Corner radius in pixels |
| `scrollSpeed` | `number` | `95` | Auto-scroll speed (px/s) |
| `flingMax` | `number` | `4200` | Maximum velocity after dragging (px/s) |
| `tearZoneRatio` | `number` | `0.26` | Fraction of viewport width for tear zone |
| `tearZoneMax` | `number` | `380` | Maximum tear zone width in pixels |

## Notes

- **WebGL Required**: This component uses Three.js and WebGL. Ensure adequate device support.
- **Performance**: More threads and segments increase visual fidelity but impact performance. Use lower values on mobile devices.
- **Interaction**: Users can click and drag to interact; releasing applies momentum-based flinging.
- **Reduced Motion**: Respects `prefers-reduced-motion` by disabling the wobble/flutter effect.
- **Concept**: Images are sliced into horizontal ribbons that behave like fabric threads in a loom, unraveling as they approach the edges.
