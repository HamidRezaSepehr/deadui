## Props

| Prop            | Type                                                                  | Default            | Description                                                            |
| --------------- | --------------------------------------------------------------------- | ------------------ | ---------------------------------------------------------------------- |
| `children`      | `string`                                                              | —                  | The text to split and reveal. Required.                               |
| `variant`       | `"blur-in" \| "fade-up" \| "slide-stagger" \| "scale-pop" \| "rise-color" \| "slide-left-color" \| "scale-blur-color" \| "diagonal-blur-color" \| "flip-x-color" \| "heavy-flip-color" \| "flip-top-color" \| "mask-reveal" \| "blur-grain" \| "blur-grain-bright" \| "scale-blur-grain" \| "skew-blur-grain"` | `"blur-in"` | Animation style. The `*-color` variants reveal from a dimmed gray to white. `mask-reveal` clips characters as they rise. The four `*-grain` variants are the Codrops ScrollBlurTypography demos: scroll-scrubbed (`ease:'none'`) unblur-over-a-grain-tile, with `blur(10px) brightness(0|30|50%)` → `blur(0) brightness(100%)`, `scaleY 0.1`×`scaleX 1.8`, and word-split `skewX -20` respectively. |
| `duration`      | `number`                                                              | `0.8`              | Animation duration in seconds.                                        |
| `delay`         | `number`                                                              | `0`                | Delay before the animation starts.                                    |
| `stagger`       | `number`                                                              | `0.05`             | Delay between each split unit.                                        |
| `splitBy`       | `"chars" \| "words" \| "lines"`                                       | `"chars"`          | How to split the text.                                                |
| `start`         | `string`                                                              | `"top 85%"`        | ScrollTrigger start position.                                         |
| `end`           | `string`                                                              | `"bottom top"`     | ScrollTrigger end position.                                           |
| `once`          | `boolean`                                                             | `true`             | Set `false` to replay on every entry from either scroll direction.     |
| `scrub`         | `boolean \| number`                                                   | `false`            | Link progress to scroll position. Wins over `once` and `toggleActions`. |
| `toggleActions` | `string`                                                              | —                  | Raw GSAP `toggleActions`, e.g. `"play none none reverse"`.             |
| `preview`       | `boolean`                                                             | `false`            | Only affects the `*-grain` variants: play once on mount (and replay on any prop change) instead of scrubbing with scroll. For non-scrolling playgrounds/previews. |

## Dependencies

- `gsap` — includes SplitText and ScrollTrigger

## Performance

- Only `transform`, `opacity`, `color` (on the `*-color` variants) and
  `filter: blur` (on the blur variants) are animated, so the reveal stays off
  the layout path.
- The four `*-grain` variants add a scoped `background-image` tile behind the
  text (the exact 200×200 semi-transparent PNG shipped with the Codrops demo).
  The tile ships beside the component and is imported relatively, so the
  bundler emits it — the CLI copies it as part of `add cinematic-text`. The
  tile is on the component's own layer, not the page's `<body>`, so a
  consumer's background is untouched.
- Splitting runs once per props change and is reverted through
  `gsap.context()`, so remounting leaves nothing behind.
- The element's layout space is established before the animation runs — no
  cumulative layout shift.

## Accessibility

- `prefers-reduced-motion: reduce` is detected before the timeline is built. The
  animation is skipped entirely and the text renders in its final, fully
  readable state.
- The reveal only decorates text that is already in the DOM as real text, so
  screen readers and copy-paste are unaffected.
