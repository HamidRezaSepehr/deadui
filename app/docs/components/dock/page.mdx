# Dock

A macOS-style magnifying dock component with smooth Framer Motion physics.
Icons scale up smoothly based on cursor proximity using spring physics.

Move your cursor across the icons — they scale up with a spring effect as
they approach the pointer. The `disableMagnification` prop (not exposed above)
turns off the physics and applies a simple hover state instead.

## Usage

```tsx
import { Dock, DockIcon } from "@/components/ui/dock"
import { Zap, Heart, Star } from "lucide-react"

export function AppDock() {
  return (
    <Dock>
      <DockIcon tooltip="Lightning"><Zap size={24} /></DockIcon>
      <DockIcon tooltip="Favourite"><Heart size={24} /></DockIcon>
      <DockIcon tooltip="Bookmark"><Star size={24} /></DockIcon>
    </Dock>
  )
}
```

## Props

| Prop                   | Type                                         | Default     | Description                                                               |
| ---------------------- | -------------------------------------------- | ----------- | ------------------------------------------------------------------------- |
| `children`             | `React.ReactNode`                            | —           | `DockIcon` children. Required.                                            |
| `iconSize`             | `number`                                     | `40`        | Base size of each icon in pixels (width and height).                      |
| `iconMagnification`    | `number`                                     | `60`        | Target size when the cursor is closest (the peak scale).                  |
| `disableMagnification` | `boolean`                                    | `false`     | When `true`, the spring is bypassed and icons stay at `iconSize`.         |
| `iconDistance`         | `number`                                     | `140`       | Pixel distance over which the magnification ramps from base to peak.      |
| `direction`            | `"top" \| "middle" \| "bottom"`              | `"middle"`  | Alignment of icons within the dock container.                             |
| `className`            | `string`                                     | —           | Merged after the dock's base classes.                                     |

### DockIcon Props

| Prop        | Type                 | Default     | Description                                                  |
| ----------- | -------------------- | ----------- | ------------------------------------------------------------ |
| `children`  | `React.ReactNode`    | —           | Icon content (typically a Lucide icon). Required.            |
| `tooltip`  | `string`             | —           | Custom styled tooltip text displayed on hover.               |
| `className` | `string`             | —           | Merged after the icon's base classes.                        |

## Dependencies

- `motion` — the spring physics, motion values, and transforms
- `class-variance-authority`

## Performance

- Only `width` and `height` are animated via Motion's spring values, so the
  scaling stays on the compositor and never triggers layout reflow.
- The spring configuration (`mass: 0.1`, `stiffness: 150`, `damping: 12`)
  gives a responsive yet stable feel without overshoot.

## Accessibility

- Renders as semantic `<div>` elements with `cursor-pointer` for the icons.
- Under `prefers-reduced-motion: reduce`, the spring values resolve to their
  target instantly, so magnification still works without animation. Pass
  `disableMagnification` for a fully static variant.
- The dock container uses `backdrop-blur-md` for a frosted-glass effect that
  respects the user's `prefers-reduced-transparency` setting via the
  `supports-backdrop-blur:` prefix.
