# Reactive Dot Grid

A card with a pure Canvas dot grid background. Dots near the cursor are repelled outward, increase in size, and shift to an active color. When the pointer leaves, energy decays smoothly so dots glide back to their original positions rather than snapping instantly.

Move your pointer over the card. Dots inside the `radius` are pushed away and glow; when you leave, the `currentForce` decays at `0.12` per frame so the grid breathes back smoothly.

## How it works

Each dot calculates its distance to the cursor. If within `radius`, a squared falloff `(1 - d/radius)^2` produces the interaction intensity `t`. Repulsion pushes the dot along the `dx/dy` vector scaled by `t`, and the dot grows from `1.2px` to `3.8px`. The energy system (`currentForce` vs `targetForce`) ensures the animation stops cleanly when idle (`> 0.004` delta) and resumes instantly on pointer events.

| `colorActive` | `string` | `"#4d8dff"` | Active/nearby dot color. |

## Performance

- **Energy decay optimization**: The `requestAnimationFrame` loop pauses when `Math.abs(targetForce - currentForce) < 0.004`, reducing CPU usage when the card is idle.
- **Pure Canvas 2D**: Each frame redraws the grid with a single `clearRect()` and individual `arc()` calls — no DOM nodes per dot.
- **ResizeObserver**: Grid rebuilt only on container resize.
- **IntersectionObserver**: Animation pauses when off-screen and resumes on entry.

## Accessibility

- The canvas is `aria-hidden="true"` since it is purely decorative.
- Respects `prefers-reduced-motion`: interaction is disabled (`effectiveForce = 0`) when reduced motion is preferred.
- The card container accepts any React children, which remain fully interactive above the decorative background.
