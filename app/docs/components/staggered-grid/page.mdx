# Staggered Grid Reveal

Container-and-item pair that reveals a grid of children one after another as
it scrolls into view.

The animation belongs to the **children**, not the container: `StaggeredGrid`
owns the timing and the variant, `StaggeredItem` picks it up through context
and supplies its own initial and target state. The playground renders a 3×3
mock grid so you can watch the sequence; the real usage below shows the same
pair wrapping real content.

## Usage

```tsx
import { StaggeredGrid, StaggeredItem } from "@/components/ui/staggered-grid"

const TILES = ["Design", "Motion", "React", "GSAP", "Framer Motion", "WebGL"]

export function FeatureGrid() {
  return (
    <StaggeredGrid
      variant="scale-in"
      stagger={0.08}
      containerClassName="grid grid-cols-2 gap-4 md:grid-cols-3"
    >
      {TILES.map((tile) => (
        <StaggeredItem
          key={tile}
          className="rounded-xl border border-dead-800 bg-dead-900 p-6"
        >
          {tile}
        </StaggeredItem>
      ))}
    </StaggeredGrid>
  )
}
```

`containerClassName` is how you make the container a grid — the container
itself carries no layout classes beyond `w-full`, so your grid definition
reaches it unmerged. Putting the grid on `containerClassName` rather than
`className` also means the two never collide in `tailwind-merge`.

## Props

### `StaggeredGrid`

| Prop                | Type                                                                       | Default      | Description                                                             |
| ------------------- | -------------------------------------------------------------------------- | ------------ | ----------------------------------------------------------------------- |
| `children`          | `React.ReactNode`                                                          | —            | The items, each wrapped in a `StaggeredItem`. Required.                |
| `variant`           | `"fade-up" \| "scale-in" \| "blur-in" \| "slide-left" \| "slide-right" \| "flip-x" \| "flip-y"` | `"fade-up"` | Animation handed to every descendant item through context. |
| `stagger`           | `number`                                                                   | `0.1`        | Delay between each item, in seconds.                                   |
| `duration`          | `number`                                                                   | `0.6`        | Duration of each item's animation, in seconds.                         |
| `delay`             | `number`                                                                   | `0`          | Delay before the first item starts.                                    |
| `ease`              | `string`                                                                   | `"easeOut"`  | Easing for each item.                                                  |
| `once`              | `boolean`                                                                  | `true`       | `false` replays the sequence on every entry into view.                 |
| `threshold`         | `number`                                                                   | `0.1`        | Fraction of the container that must be visible to trigger.             |
| `rootMargin`        | `string`                                                                   | `"0px"`      | `IntersectionObserver` root margin.                                    |
| `containerClassName` | `string`                                                                  | —            | Layout classes for the grid itself.                                    |

### `StaggeredItem`

| Prop       | Type              | Default | Description                                                                |
| ---------- | ----------------- | ------- | -------------------------------------------------------------------------- |
| `children` | `React.ReactNode` | —       | The item's content. Required.                                             |
| `className` | `string`         | —       | Merged last, so it wins. `col-span-2` / `row-span-2` land here.            |

Plus every `motion.div` prop, since `StaggeredItem` extends
`HTMLMotionProps<"div">`.

## Dependencies

- `motion` — `whileInView` with `staggerChildren`
- `class-variance-authority`
- `clsx` + `tailwind-merge`

## Performance

- The stagger is a single orchestrating transition
  (`staggerChildren`) on the container, not one timer per item, so the
  browser interpolates the whole sequence on the compositor.
- Items animate `transform`, `opacity` and one `filter: blur()` on the
  `blur-in` variant — no layout-affecting properties, so nothing reflows.
- Items hold their layout space at all times: the variant is expressed as a
  Motion `initial` transform, not as a class that changes the box, so there is
  no cumulative layout shift as the grid appears.
- Grid spans (`col-span-2`, `row-span-2`) come from `className` on the item
  and are resolved before the animation starts, so a mixed-size grid keeps
  its exact layout.
- Cost scales with the number of items. Each `StaggeredItem` is its own Motion
  node; a hundred-cell grid is a hundred animated elements even though they
  share one transition.

## Accessibility

- Motion is honoured through `useReducedMotion` inside `motion/react`: with
  reduced motion the items render in their target state rather than animating
  from an offset, so nothing moves and nothing is left invisible.
- Every item is in the DOM in its final, readable state from the first frame.
  The reveal is a transition on real content, not content that appears late.
- Grid items add nothing to the tab order; any links or buttons inside them
  are the focusable elements, and focus is visible because the items never
  animate `outline`.
