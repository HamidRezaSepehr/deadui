# Avatar Circles

A horizontally stacked group of user avatars whose overlap, border radius and
size are fully adjustable. The last item in the stack can be a counter badge
(e.g. "+99") to indicate additional people. Individual avatars can also be
clickable links.

## Usage

```tsx
import { AvatarCircles } from "@/components/ui/avatar-circles"

const avatars = [
  { name: "Alice", imageUrl: "https://i.pravatar.cc/150?u=alice" },
  { name: "Bob", imageUrl: "https://i.pravatar.cc/150?u=bob" },
  { name: "Carol", imageUrl: "https://i.pravatar.cc/150?u=carol" },
  { name: "Dave", imageUrl: "https://i.pravatar.cc/150?u=dave" },
]

export function Team() {
  return <AvatarCircles avatars={avatars} numPeople={12} />
}
```

### With linked avatars

Individual avatars can link to external pages. The `href` property wraps
the avatar in an `<a>` tag with the avatar's name as the title and a hover
lift effect (`z-50`, `scale-110`):

```tsx
const avatars = [
  {
    name: "GitHub",
    imageUrl: "https://i.pravatar.cc/150?u=github",
    href: "https://github.com",
  },
]

export function LinkedTeam() {
  return <AvatarCircles avatars={avatars} numPeople={8} />
}
```

## The `avatars` array

Each entry has the following shape:

| Field     | Type     | Description                            |
| --------- | -------- | -------------------------------------- |
| `name`    | `string` | Avatar name (used as `alt` and `title`) |
| `imageUrl` | `string` | URL to the avatar image                |
| `href`    | `string` | (Optional) Link URL for clickable avatar |

The `numPeople` prop displays a styled {'"+{numPeople}"'} badge at the end of the
stack. Use it to communicate the total number of people when only a subset
is shown.

## Props

| Prop       | Type                                                   | Default    | Description                                     |
| ---------- | ------------------------------------------------------- | ---------- | ----------------------------------------------- |
| `avatars`  | `AvatarItem[]`                                         | — (required) | Array of avatar objects (name, imageUrl, href) |
| `numPeople` | `number`                                                | —           | Number to display in the "+X" counter badge     |
| `size`     | `'sm' \| 'md' \| 'lg' \| 'xl'`                         | `'md'`      | Avatar size                                     |
| `overlap`  | `number`                                                | `16`        | Pixels of overlap (translates to negative margin-left) |
| `radius`   | `'sm' \| 'md' \| 'lg' \| 'full'`                       | `'full'`    | Border radius of each avatar                    |
| `bordered` | `boolean`                                               | `true`      | Adds a separating border between avatars        |
| `className` | `string`                                                | —           | Additional classes for the container            |
| `...props` | `HTMLAttributes<HTMLDivElement>`                        | —           | Spread onto the container                       |

## Performance

- Pure CSS — no JS animation, no layout thrash. Every avatar is positioned
  with a single inline `margin-left` and `z-index`.
- Images use `object-cover` so aspect ratios are preserved at any size.
- Hover effects are compositor-only (`transform: scale`, `z-index`).

## Accessibility

- Every avatar receives `title={avatar.name}` so screen readers see the name
  even when the image fails to load.
- Avatars with an `href` are wrapped in native `<a>` tags — fully keyboard
  navigable with standard focus indicators.
- The counter element is a plain `<div>` with visible text. No aria attributes
  needed — the number is already readable.
