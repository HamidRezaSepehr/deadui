# Spotlight Hover Card

Mouse-tracking radial spotlight with a border-masked glow and optional 3D tilt.

Move the pointer across the card: the radial gradient follows it, and the
border ring lights up without the glow ever bleeding onto the card face.
`glowType` decides which layers are painted — `border` is masked to the 1px
ring, `background` fills the surface, `both` does each, `none` disables the
spotlight entirely and leaves only the static hairline border.

```tsx
export function PricingCard() {
  return (

    </SpotlightCard>
  )
}
```

## Props

| Prop                 | Type                                                     | Default                       | Description                                                                |
| -------------------- | -------------------------------------------------------- | ----------------------------- | -------------------------------------------------------------------------- |
| `children`           | `React.ReactNode`                                        | —                             | Card content, wrapped in a `p-6` layer above the glow. Required.            |
| `glowType`           | `"border" \| "background" \| "both" \| "none"`           | `"both"`                      | Which glow layers to paint.                                                |
| `enableTilt`         | `boolean`                                                | `false`                       | Track the pointer with a 3D rotation as well as the spotlight.              |
| `tiltIntensity`      | `number`                                                 | `10`                          | Maximum rotation in degrees at a corner.                                   |
| `spotlightColor`     | `string`                                                 | `"rgba(255, 255, 255, 0.15)"` | Any CSS colour for the radial gradient.                                    |
| `spotlightSize`      | `number`                                                 | `300`                         | Gradient diameter in pixels.                                               |
| `spotlightOpacity`   | `number`                                                 | `1`                           | Gradient alpha multiplier, `0` to `1`.                                    |
| `shape`              | `"rounded" \| "soft" \| "sharp"`                         | `"rounded"`                   | Corner radius.                                                             |
| `borderColor`        | `string`                                                 | `"rgba(255, 255, 255, 0.1)"` | Resting hairline border.                                                   |
| `hoveredBorderColor` | `string`                                                 | `"rgba(255, 255, 255, 0.3)"` | Colour of the masked border glow.                                          |
| `style`              | `React.CSSProperties`                                    | —                             | Merged last, so it wins per property over the generated CSS variables.      |

## Dependencies

- `class-variance-authority`
- `clsx` + `tailwind-merge`

No animation library. The tracking is a `mousemove` handler that writes CSS
custom properties.

## Performance

- **Zero React re-renders while tracking.** The pointer handler writes
  `--mouse-x`, `--mouse-y`, `--rotate-x` and `--rotate-y` straight onto the
  DOM node — no `useState`, no `useReducer`. A `mousemove` costs one style
  write on one element.
- Only `opacity` and `transform` are animated, and the layer that fades in is
  a `radial-gradient` background, so the card itself never re-lays-out.
- With `enableTilt` the card gets `will-change-transform`, but only then — a
  permanent layer promotion on a flat card is wasted GPU memory.
- The 300ms glow fade is a CSS transition on a single absolutely positioned
  layer, and it is suppressed under reduced motion.

## Accessibility

- The glow layers are `aria-hidden` decorative overlays; they are never
  announced and they take no pointer events, so they cannot swallow a click.
- Under `prefers-reduced-motion: reduce` the glow fade transitions are
  removed (`motion-reduce:transition-none`) and the 3D tilt is skipped
  entirely — the card stays flat and still tracks its border colour only.
- The card is a plain `div` and adds nothing to the tab order. If you put a
  link or button inside it, that child remains the focusable element.
