# Spinning Text

Draw a single continuous string along a perfect circle and rotate it infinitely.
The text follows the curvature exactly thanks to native SVG `<textPath>` — no
per-character transforms, no SVG text paths hand-rolled, crisp at any size.

## Usage

Pass a single `text` string. To make the ring feel continuous, **repeat the
string a few times and end with a separator** (`•`, `★`, `·`, …) so the seam
blends into the circle:

```tsx
import { SpinningText } from "@/components/ui/spinning-text"

export function HeroRing() {
  return (
    <SpinningText text="DEAD UI • ANIMATIONS • FREE COMPONENTS • " />
  )
}
```

### Sizing

The component sizes itself to whatever Tailwind class you give it — the circle
path is defined in a 100×100 SVG viewBox, so it scales perfectly:

```tsx
{/* small */}
<SpinningText text="SMALL • SPIN • " className="w-32 h-32" />

{/* large */}
<SpinningText text="LARGE • SPIN • " className="w-72 h-72" />
```

### Custom center content

Replace the default black circle with any React node using the `centerContent`
prop. It sits in a static layer above the rotating ring:

```tsx
import { Command } from "lucide-react"
import { SpinningText } from "@/components/ui/spinning-text"

export function BrandedRing() {
  return (
    <SpinningText
      text="DEAD UI • CREATE • SHIP • REPEAT • "
      className="w-72 h-72"
      centerContent={
        <div className="flex h-16 w-16 items-center justify-center rounded-full bg-red-500 shadow-lg">
          <Command size={26} className="text-white" />
        </div>
      }
    />
  )
}
```

### Direction and speed

`direction` accepts `"clockwise"` (default) or `"counter-clockwise"`.
`duration` controls the time for one full rotation in seconds:

```tsx
<SpinningText
  text="FAST • REVERSE • LOOP • "
  className="w-64 h-64"
  duration={5}
  direction="counter-clockwise"
/>
```

## How it works

The rotation uses Tailwind's built-in `@keyframes spin` applied as an inline
`animation` style, so **no Tailwind config injection is required**. The SVG
ring rotates as one rigid body; the center content stays static above it.

The circular path is drawn in the SVG viewBox with center `50,50` and radius
`40`:

```svg
<path d="M 50,50 m -40,0 a 40,40 0 1,1 80,0 a 40,40 0 1,1 -80,0" />
```

The `<text>` uses `fill-current` and the theme's `text-foreground` colour, so
it inherits the text colour from its container — style it however you like.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | — (required) | The string drawn along the circular path. Repeat it with separators to fill the ring. |
| `duration` | `number` | `10` | Seconds per full rotation. Lower is faster. |
| `direction` | `"clockwise" \| "counter-clockwise"` | `"clockwise"` | Spin direction. Reversed via `animation-direction`. |
| `centerContent` | `React.ReactNode` | A `bg-dead-950` circle | Content rendered in the static centre of the ring. Pass any React node. |
| `className` | `string` | — | Wraps the whole component (e.g. `w-64 h-64` to control size). |
| `...props` | `HTMLAttributes<HTMLDivElement>` | — | Spread onto the container. |

## Dependencies

- `clsx`
- `tailwind-merge`

## Performance

- Zero JavaScript per frame — the rotation is a pure CSS `animation` on the
  compositor thread.
- The SVG renders the ring once; only the container's `transform` animates, so
  there is no per-frame re-layout or re-rasterisation.
- Because Tailwind's `@keyframes spin` is built-in, no Tailwind config
  injection is needed and the component has zero setup cost.

## Accessibility

- Under `prefers-reduced-motion: reduce` the rotation stops and the full
  circle is revealed as a static arrangement.
- The text is drawn inside an SVG `<text>` element. If the ring is decorative,
  add `aria-hidden="true"` to the wrapper; if it carries meaning, pair it with
  accessible text (e.g. inside `centerContent`).
