# Infinite Blur Marquee

Media-agnostic infinite marquee: images, SVGs, videos and mixed HTML cards on
one seamless track — with edge blur, vertical mode, pause-on-hover, reverse,
uniform item styling and two scroll-reactive modes.

Hover the strip to test `pauseOnHover`. `speed` is the duration of one full loop
in seconds, so **lower is faster**. Set `scrollLinked` to `true` to freeze the
autoplay and scrub the strip from its container's own progress through the
viewport instead: it holds still while the strip is off-screen, then glides
through one full period as you scroll it into and back out of view. `reverse`
flips which way that travel runs.

For a scroll-reactive loop that never stops, set `scrollVelocity` to `true`
instead: the strip keeps auto-playing and its velocity is bound to your scroll.
Scrolling **down** drives it in its default direction (faster), scrolling **up**
reverses it (faster), and when you stop it keeps moving in the last direction at
normal speed. `reverse` picks whether the default direction is left
(`false`) or right (`true`).

## Usage

```tsx
import { Marquee } from "@/components/ui/marquee"

const TAGS = ["Design", "Motion", "React", "GSAP", "Framer Motion"]

export function TagStrip() {
  return (
    <Marquee blur="edges" speed={30} pauseOnHover>
      {TAGS.map((tag) => (
        <span key={tag} className="px-6 font-mono text-sm text-dead-200">
          {tag}
        </span>
      ))}
    </Marquee>
  )
}
```

## Styling every item with `itemClassName`

`itemClassName` is applied to each repeated wrapper — together with
`overflow-hidden` — so a border radius clips the media inside instead of
leaving square corners poking out:

```tsx
<Marquee itemClassName="rounded-xl p-4" gap={16}>
  {LOGOS.map((logo) => (
    <img key={logo} src={logo} alt="" className="h-24 w-44 object-cover" />
  ))}
</Marquee>
```

Videos work the same way. With `gap={0}` each video fills its own wrapper edge
to edge, so the wrapper's radius is what rounds the clip:

```tsx
<Marquee itemClassName="rounded-2xl" gap={0} repeat={5}>
  <video src="/clips/loop.mp4" autoPlay muted loop playsInline className="h-44 w-80 object-cover" />
</Marquee>
```

Container-level skinning lives in the `bg` and `border` variants:

```tsx
<Marquee bg="surface" border="default">
  {TAGS.map((tag) => (
    <span key={tag} className="px-6 font-mono text-sm text-dead-200">
      {tag}
    </span>
  ))}
</Marquee>
```

## Mixing fonts inside the children

Children are ordinary markup, so every element inside the strip keeps its own
typography — a card title can use the sans family while its body copy uses the
serif:

```tsx
<Marquee gap={24} speed={45}>
  {CARDS.map((card) => (
    <article
      key={card.title}
      className="flex w-[380px] shrink-0 overflow-hidden rounded-xl border border-dead-800 bg-dead-900"
    >
      <img src={card.image} alt="" className="h-36 w-32 shrink-0 object-cover" />
      <div className="flex flex-col gap-2 p-4">
        <h3 className="font-sans text-sm font-semibold text-dead-50">{card.title}</h3>
        <p className="font-serif text-[13px] leading-relaxed text-dead-400">{card.body}</p>
      </div>
    </article>
  ))}
</Marquee>
```

## Props

| Prop            | Type                                                   | Default       | Description                                                       |
| --------------- | ------------------------------------------------------ | ------------- | ----------------------------------------------------------------- |

| `direction`     | `"horizontal" \| "vertical"`                           | `"horizontal"` | Axis of travel. `vertical` also fixes a `500px` height.           |
| `blur`          | `"none" \| "edges" \| "left" \| "right"`               | `"edges"`     | Mask applied to the container. `edges` fades both ends.           |
| `speed`         | `number`                                               | `30`          | Seconds for one full loop. **Lower is faster.**                  |
| `gap`           | `number`                                               | `16`          | Pixels between items inside one copy.                            |

| `reverse`       | `boolean`                                              | `false`       | Play the animation backwards.                                    |
| `repeat`        | `number`                                               | `4`           | How many copies of `children` are rendered.                      |
| `scrollLinked`  | `boolean`                                              | `false`       | Disable autoplay and scrub the offset from the container's own progress through the viewport. Travels exactly one period across the strip's on-screen life, so it never leaves its box; `reverse` flips the direction. |
| `scrollVelocity`| `boolean`                                              | `false`       | Keep autoplay running and bind the loop's velocity to page scroll. Scrolling down drives the default direction (faster), scrolling up reverses it (faster); the last direction persists at normal speed when scrolling stops. `reverse` sets the default direction. Takes effect only when `scrollLinked` is `false`. |
| `itemClassName` | `string`                                               | —             | Applied to every repeated wrapper alongside `overflow-hidden` — use it for uniform radius, padding or background on each copy. |
| `bg`            | `"none" \| "surface" \| "elevated"`                    | `"none"`      | Container background variant.                                     |
| `border`        | `"none" \| "default"`                                  | `"none"`      | Container border variant.                                         |
| `className`     | `string`                                               | —             | Merged after the variant classes, so it wins on conflicts.        |

## Dependencies

- `class-variance-authority`
- `clsx` + `tailwind-merge`

No animation library: the loop is a CSS keyframe on a transform, declared in
`app/globals.css` as `animate-marquee` / `animate-marquee-vertical`.

## Performance

- The track animates `transform` only, on a `will-change-transform` layer, so
  the whole loop is one compositor pass and never touches layout.
- Each copy is a self-contained period with its inter-item gap baked in, and
  the keyframe translates exactly one copy's width — so the wrap point is
  pixel-perfect and there is no visible jump.
- `scrollLinked` replaces the keyframe with a scroll-fed `translate` — still
  compositor-only. The offset comes from the container's own
  `getBoundingClientRect()` measured against the viewport, wrapped to a single
  period so the track's spare copies always cover the box, and refreshed from
  `passive` scroll and resize listeners plus a `ResizeObserver`.
- `scrollVelocity` is the one mode driven by `requestAnimationFrame` (a CSS
  keyframe cannot have its speed or direction changed mid-flight): it still only
  writes `transform` on the same `will-change-transform` layer, and the travel
  distance is wrapped at exactly one period so the loop stays seamless. It also
  short-circuits under `prefers-reduced-motion`.
- `repeat` is the cost dial: each copy is a full render of `children`, so
  `repeat={4}` on an expensive child is 4x the DOM. Video children in
  particular multiply their element count by `repeat`.

## Accessibility

- The track carries `motion-reduce:[animation:none]!`, so under
  `prefers-reduced-motion: reduce` the strip renders as static content
  instead of moving.
- The duplicate copies are decorative repetitions of real text. They are not
  hidden from assistive tech, so a screen reader will read the strip
  `repeat` times — lower `repeat` if that matters for your content.
- The strip is not interactive and takes no focus, so it adds nothing to the
  tab order.
