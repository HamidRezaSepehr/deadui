Scroll through the preview. Words fill left to right as the section passes,
and the transition band between dim and filled text **widens with scroll
velocity** — flick the page and the red band smears across several words at
once. `scrub` is the easing: `0` tracks the scroll position exactly, higher
lets the timeline lag behind it.

`height` is the scroll range the fill is spread across, so a taller section
means a slower, longer fill.

## Usage

```tsx
import { TextFillAnimation } from "@/components/ui/text-fill-animation"

export function Manifesto() {
  return (
    <TextFillAnimation
      text="Dead simple animations for React."
      primaryColor="#ef4444"
      scrub={0.25}
      height="250vh"
      showDetails={false}
    />
  )
}
```

With no props at all it renders a full section of default copy with the
decorative corner labels on. `showDetails={false}` strips those for a clean
placement inside a page.

## Props

| Prop                | Type                       | Default                                     | Description                                                                  |
| ------------------- | -------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------- |
| `text`              | `string`                   | A full sentence about Dead UI              | The copy that fills. Split into words and characters.                       |
| `showDetails`       | `boolean`                  | `true`                                      | Corner labels: the "Scroll ↓" marker and the GSAP / SplitText / Velocity list. |
| `textColor`         | `string`                   | `"var(--color-foreground)"`                | Colour of the fully filled text.                                            |
| `primaryColor`      | `string`                   | `"#ff6b00"`                                | The velocity-reactive colour in the middle of the transition.               |
| `dimColor`          | `string`                   | 20% of the foreground mixed with the background | Colour of the text before it fills.                                      |
| `backgroundColor`   | `string`                   | `"var(--color-background)"`                | Section background.                                                         |
| `velocityPrimary`   | `boolean`                  | `true`                                      | `false` drops the velocity response and maps `primaryColor` straight to the final state. |
| `textSize` / `textWidth` | `string`              | `"5vw"` / `"80%"`                          | Desktop type size and measure.                                              |
| `tabletTextSize` / `tabletTextWidth` | `string`     | `"6.5vw"` / `"88%"`                        | Overridden between 641px and 1024px.                                        |
| `mobileTextSize` / `mobileTextWidth` | `string`     | `"8vw"` / `"95%"`                          | Overridden at 640px and below.                                              |
| `start`             | `string`                   | `"top top"`                                | ScrollTrigger start.                                                        |
| `end`               | `string`                   | `"bottom bottom"`                          | ScrollTrigger end.                                                          |
| `scrub`             | `number \| boolean`        | `0.25`                                     | Scroll smoothing. `0` tracks exactly.                                       |
| `height`            | `string \| number`         | `"250vh"`                                  | Scroll range the fill is spread across.                                     |
| `viewportHeight`    | `string`                   | `"100vh"`                                  | Height of the sticky inner viewport.                                        |
| `scroller`          | `HTMLElement \| Window \| RefObject` | —                              | Custom scroll container, for a nested scroller.                             |
| `trigger`           | `HTMLElement \| RefObject` | —                                          | Override the ScrollTrigger element. Defaults to the section itself.         |

## Dependencies

- `gsap` — ScrollTrigger and SplitText, both required

Ships two files: the component and `text-fill-animation.module.css`.

## Performance

- The section reserves its scroll range with a real height (`height`,
  default `250vh`) and pins the visible viewport with `position: sticky`, so
  nothing about the fill shifts the page as it runs. No cumulative layout
  shift.
- Only `color` is animated, per character, plus one blurred `radial-gradient`
  glow behind the heading. Nothing touches layout, so there is no reflow on
  any frame of the scrub.
- The heading's layout space is established before the timeline starts — the
  characters are always in the DOM and always occupy their box.
- SplitText runs once per props change and is reverted through
  `gsap.matchMedia().revert()` on cleanup, so remounting leaves no orphaned
  spans and no second ScrollTrigger behind.

## Accessibility

- Under `prefers-reduced-motion: reduce` the whole timeline is skipped. The
  CSS module collapses the section to `height: auto`, un-sticks the viewport
  and removes the per-character transition, so the copy renders once, fully
  filled and static — no scroll is required to read it.
- `SplitText` is created with `aria: "auto"`, which keeps the split spans out
  of the accessibility tree. The heading is read as the single sentence a
  human wrote, not as one node per character.
- The corner labels are real text, so they are announced; pass
  `showDetails={false}` if they are decoration for your page.
