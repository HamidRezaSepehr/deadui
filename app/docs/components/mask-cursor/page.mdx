# Mask Cursor

A wrapper that renders its `children` TWICE: a base layer in normal flow (visible everywhere) and a masked overlay layer clipped by a circular SVG `mask-image` that follows the cursor. Move the pointer: the circle grows; the text inside the circle flips to `maskTextClassName`. The mask layer renders only after the first pointer move (`ready` flag) to avoid a corner flash at mount.

The mechanism is pure CSS masking — not `mix-blend-mode`. The base layer shows `baseTextClassName` (default white); the masked overlay shows `maskTextClassName` (default black) and has its own `maskBackgroundColor`. A transparent background (`"transparent"`) produces a pure text-color swap; a solid color (e.g. `"#ec4e39"`) produces the original Olivier-style spotlight overlay.

## Usage

### Mode A — pure text-color swap (`transparent` background)

```tsx
import { MaskCursor } from "@/components/ui/mask-cursor"

export function Hero() {
  return (
    <MaskCursor
      bgClassName="bg-zinc-500"
      baseTextClassName="text-white"
      maskTextClassName="text-black"
      maskBackgroundColor="transparent"
    >
      <p>A visual designer.</p>
    </MaskCursor>
  )
}
```

### Mode B — original spotlight overlay (solid mask background)

```tsx
<MaskCursor
  bgClassName="bg-black"
  baseTextClassName="text-[#afa18f]"
  maskTextClassName="text-black"
  maskBackgroundColor="#ec4e39"
  textClassName="text-5xl md:text-7xl font-black leading-none tracking-tight"
  contentClassName="w-full max-w-[1000px] p-10 text-center"
>
  <p>
    I&apos;m a <span className="text-[#ec4e39]">selectively skilled</span> product designer.
  </p>
</MaskCursor>
```

## How it works

Two identical text layers are stacked inside the container:
1. **Base layer** (`baseLayerClassName`, `z-0`) — flows normally, defines the container size.
2. **Mask overlay layer** (`maskLayerClassName`, `z-10`, `pointer-events-none`, `aria-hidden`) — clipped by a circular `mask-image` that tracks the cursor. The mask uses an inline SVG circle (`fill="white"`) as the `maskImage`, with `maskRepeat: no-repeat`.

The mask position and size are driven by `useMotionValue` + `useSpring` (not `useState`), so the circle follows with configurable lag and overshoot. The cursor position is measured **relative to the container** (`getBoundingClientRect` offset subtracted), and the rect is refreshed on scroll, resize, and the first mouse move. Without relative tracking, a component lower on the page would drift.

The mask layer renders only after the first pointer move (`ready` flag) to prevent a corner flash at mount. When `disabled`, the base layer renders alone with no listener overhead.

## Contrast rule

The container background (`bgClassName`) must contrast with both `baseTextClassName` and `maskTextClassName`. The default (`bg-zinc-500`, white ↔ black) reads clearly; a dark-theme pairing uses `bg-black` with `text-white` ↔ `text-emerald-400`. With `maskBackgroundColor="transparent"`, the swap is pure color; with `maskBackgroundColor="#ec4e39"`, the mask layer shows the background through the circle (the original spotlight style).

## Caveats

- The effect requires pointer movement; there is no touch equivalent by default. Wrap with `disabled` for coarse-pointer contexts.
- The mask layer duplicates `children`, so assistive technology sees the content twice; the mask layer carries `aria-hidden` and `pointer-events-none`.
- The component is visual-only; the accessible experience is the base layer.
- No `mix-blend-mode`, no `framer-motion` animation props, no WebGL, no `three` — pure CSS masking.

## Dependencies

- `motion`

## Performance

- Mouse position is `useMotionValue` updated by `window.mousemove`; zero React re-renders per mouse move.
- The spring transforms (`useSpring` + `useTransform`) compute `maskPosition` and `maskSize` entirely in the compositor thread.
- The mask layer mounts once (`ready` flag) and unmounts when `disabled`.

## Accessibility

- Base layer renders real text content for assistive technology.
- Mask layer is hidden (`aria-hidden`) and non-interactive (`pointer-events-none`).
- The component is purely visual; the accessible experience is the base layer text.
