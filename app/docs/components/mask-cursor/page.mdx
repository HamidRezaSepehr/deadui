# Mask Cursor

A wrapper that renders its `children` TWICE: a base layer in normal flow and a mask layer clipped by a circular CSS `mask-image` following the cursor. Move the pointer over the container: the circle grows, the text inside the circle flips to `maskColorClass`, and the rest stays at `baseColorClass`. The mask layer renders only after the first pointer move to avoid a corner flash.

## How it works

Two identical text layers are stacked:
1. The base layer (`baseColorClass`, `z-0`) defines the container size and provides the default text.
2. The mask layer (`maskColorClass`, `z-10`, `pointer-events-none`, `aria-hidden`) is clipped by a circular `mask-image`: `radial-gradient(circle at center, #000 50%, transparent 50%)`. Only the area inside the circle shows the mask layer; everything outside shows the base layer.

The circle follows the cursor via `useMotionValue` + `useSpring` (not `useState`, so zero React re-renders per mousemove). The cursor position is measured relative to the container (`getBoundingClientRect` offset subtracted), and the rect is refreshed on scroll, resize, and the first mouse move. The size grows between `circleSize` and `hoverCircleSize` via an underdamped spring (overshoot visible at `sizeDamping` below ~14).

The mask layer renders only after the first pointer move (`ready` flag) to prevent a corner flash at mount. When `disabled`, the base layer renders alone with no listener overhead.

## Contrast rule

The container background (`bgClassName`) must contrast with both `baseColorClass` and `maskColorClass`. The default (`bg-zinc-500`, white ↔ black) reads clearly; a dark-theme pairing uses `bg-black` with `text-white` ↔ `text-emerald-400`.

## Caveats

- The mask is CSS-only (`radial-gradient`) — no WebGL, no canvas, no `framer-motion`.
- The mask layer duplicates `children`, so assistive tech sees the content twice; the mask layer carries `aria-hidden` and `pointer-events-none`.
- No touch equivalent by default: the circle responds to pointer movement, not touch. Wrap with `disabled` for coarse-pointer contexts.

## Dependencies

- `motion`

## Performance

- Mouse and size are `useMotionValue` objects updated by `window.mousemove`; no React re-render per move.
- The spring transforms (`useSpring` + `useTransform`) compute `maskPosition` and `maskSize` entirely in the compositor.
- The mask layer mounts only once (`ready` flag) and unmounts only when `disabled`.

## Accessibility

- Base layer renders real text content for assistive technology.
- Mask layer is hidden (`aria-hidden`) and non-interactive (`pointer-events-none`).
- The component is purely visual; the accessible experience is the base layer text.
