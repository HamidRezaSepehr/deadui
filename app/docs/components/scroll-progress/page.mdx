# Scroll Progress

A lightweight scroll progress indicator with horizontal bar and circular SVG
variants, driven by `requestAnimationFrame` for 60fps performance.

## Usage

### Horizontal bar (navbar integration)

```tsx
import { ScrollProgress } from "@/components/ui/scroll-progress"

export function Layout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <ScrollProgress variant="horizontal" color="default" />
      <nav>{/* your navbar */}</nav>
      <main>{children}</main>
    </>
  )
}
```

### Circular indicator (corner floating)

```tsx
import { ScrollProgress } from "@/components/ui/scroll-progress"

export function Layout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <ScrollProgress
        variant="circular"
        color="default"
        showPercentage
        size={56}
        strokeWidth={5}
        className="top-4 right-4"
      />
      <main>{children}</main>
    </>
  )
}
```

### Scoped to a container

```tsx
import { useRef } from "react"
import { ScrollProgress } from "@/components/ui/scroll-progress"

export function ScrollableSection() {
  const containerRef = useRef<HTMLDivElement>(null)

  return (
    <div ref={containerRef} className="relative h-[400px] overflow-y-auto">
      <ScrollProgress
        variant="horizontal"
        color="default"
        containerRef={containerRef}
        className="!sticky top-0"
      />
      <div className="h-[1200px] p-8">
        {/* tall content */}
      </div>
    </div>
  )
}
```

### Gradient bar

```tsx
<ScrollProgress variant="horizontal" color="gradient" className="h-2" />
```

### Gradient circle (larger, bottom-right)

```tsx
<ScrollProgress
  variant="circular"
  color="gradient"
  size={72}
  strokeWidth={6}
  showPercentage
  className="bottom-6 right-6 top-auto"
/>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"horizontal" \| "circular"` | `"horizontal"` | Which indicator style to render. |
| `color` | `"default" \| "gradient" \| string` | `"default"` | `"default"` uses `bg-dead-accent` (horizontal) or `text-dead-accent` (circular). `"gradient"` uses `from-dead-accent to-dead-border`. Any other string is passed as a Tailwind class or CSS color. |
| `showPercentage` | `boolean` | `false` | When `true`, renders the current percentage text centred inside the circular variant. |
| `size` | `number` | `48` | Diameter in pixels of the circular SVG. |
| `strokeWidth` | `number` | `4` | Thickness of the circular stroke in pixels. |
| `containerRef` | `RefObject<HTMLElement \| null>` | — | When provided, tracks this element's scroll position instead of `window` and uses `absolute` positioning within it. The container must have `position: relative` and `overflow`. |
| `className` | `string` | — | Tailwind classes for the outer container. |

## Dependencies

- `clsx`
- `tailwind-merge`

## Performance

- The scroll listener uses `requestAnimationFrame` — a single rAF loop reads
  the scroll position and computes the ratio once per frame, so the callback
  runs at most 60 times per second and never queues redundant re-renders.
- The horizontal variant writes `width` as a percentage; the circular variant
  writes SVG `strokeDashoffset` — both are GPU-composited properties that
  trigger only a paint (no layout recalc).
- No CSS transitions are applied to the progress elements, so the indicator
  updates instantly with zero perceptible lag.

## Accessibility

- The component is decorative — it provides no interactive functionality and
  does not trap focus.
- Under `prefers-reduced-motion` the component continues to update visually
  since its motion is a direct reflection of scroll position rather than a
  decorative animation.
