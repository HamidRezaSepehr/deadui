# Text Video Mask

A component that uses SVG masks with `foreignObject` to clip a playing video into the shape of text. Perfect for creating stunning hero sections and premium visual effects.

## Usage

```tsx
<TextVideoMask
  videoSrc="https://example.com/video.mp4"
  textClassName="text-6xl font-black text-black"
>
  Your Text Here
</TextVideoMask>
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `videoSrc` | `string` | - | The URL of the video to play (MP4 format recommended) |
| `children` | `React.ReactNode` | - | The text or HTML content that will act as the mask |
| `textClassName` | `string` | - | Additional classes for styling the text content |
| `className` | `string` | - | Additional classes for the container |

## Features

- **SVG Mask Technique**: Uses `<svg><defs><mask><foreignObject>` for maximum compatibility
- **Auto-playing Video**: Includes `autoPlay`, `loop`, `muted`, and `playsInline` for cross-browser support (including mobile Safari)
- **Tailwind Compatible**: Style your text with any Tailwind classes through `textClassName`
- **Complex HTML Support**: Render multi-line text, headings, or complex layouts as the mask
- **Collision-Free**: Uses `React.useId()` to generate unique mask IDs

## Performance Notes

- Use short, optimized, muted MP4 videos for best performance
- Videos should be compressed appropriately for web use
- Avoid very large video files as they may impact load times
